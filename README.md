# 麻雀れんしゅう 🀄

スマホのブラウザで遊べる、**打ち筋サポートつき**の4人打ち麻雀の練習アプリです。
あなたと CPU 3人で対局します。

GitHub Pages で公開すると `https://<ユーザー名>.github.io/<リポジトリ名>/` でそのまま遊べます。
ホーム画面に追加すると、アプリのように全画面で起動できます（一度開けばオフラインでも動きます）。

## できること

### 🎯 打ち筋サポート（設定・対局画面の上のボタンで切り替え）

| モード | 内容 |
|---|---|
| **打つ前のヒント** | 手牌の上に ◎（おすすめ）○（良い）△（まあまあ）×（シャンテン数が戻る）と、**切ったときの有効牌の残り枚数**を表示。牌をタップすると「その牌を切ると…」の説明（シャンテン数・受け入れ牌・テンパイ時の待ちと点数・フリテン/役なし/ドラの注意）が出て、もう一度タップで切ります。 |
| **打った直後の指摘** | 切った直後に「最善／良い／もう一歩／要注意」の評価と理由を表示（例：「受け入れが 23枚 → 12枚 に減りました」「リーチ者に危険な牌です。現物の○○がありました」）。 |
| なし | サポートなしで腕試し。 |

- **危険度表示**：リーチを受けているときは、各牌の放銃リスク（現物・スジ・壁・字牌の見え方から推定）を色で表示し、2シャンテン以上なら「降り」、1シャンテンなら「回し打ち」をすすめます。
- **鳴き・ロンの助言**：ポン・チーできるとき、鳴いた後のシャンテン数・役の有無から「鳴く／スルー」をおすすめします。
- **🎯 狙える役**：卓の右下のボタンで、いま狙える役の一覧を**見込み（%）つき**で表示。役名をタップすると、役の説明・引くと進む牌・使っている牌／使っていない牌・狙い方のコツが見られます。%は、見えていない牌からランダムにツモる試し打ち（モンテカルロ法）で見積もった目安で、ポン・チー・ロンや他家の和了による局の終了も考えています。
- **↩ 待った**：一手戻して打ち直せます。山の並びと CPU の判断は同じなので、「この牌を切っていたらどうなったか」をそのまま試せます。
- **自分の方針（自動・攻め・守り）**：助言を、あなたの方針に合わせて切り替えます。「守り」は和了を狙わず放銃しない事に専念（現物・スジ・カベの安全な牌を最優先でおすすめ。手牌の上の表示も危険度に。鳴き・リーチ・暗槓はおすすめしない。切った後の評価も安全さだけで判定）。「攻め」はリーチを受けても和了を優先。「自動」はリーチを受けたら守りに切り替えます。対局中の「方針」ボタンと設定で変更できます。
- **👀 相手の手牌を見る（練習モード）**：対局中に他家の手牌を表向きで表示（卓の左下のボタン／「☰」メニュー／設定）。テンパイ・待ち・リーチ・フリテンも出ます。局の終わりと終局のあとは、結果画面で全員の手牌を確認できます。
- **効果音（BGMなし）**：牌を切る音・ポン／チー／カン・リーチ・ロン／ツモ・和了（満貫以上・役満は豪華に）・放銃・流局・終局の順位ごとの音・局のはじまりの牌をかき混ぜる音。音声ファイルは使わず、Web Audio API でその場で合成しています。メニューと設定でオン／オフ・音量を変更できます。
- **河の最新の捨て牌を強調**：いちばん新しい捨て牌には黄色い枠がつきます。ポン・チー・ロンの確認が出たときは、対象の牌が太く光る枠で囲まれ、確認の欄にも牌の絵が出ます。
- **結果を隠して卓を見る**：局の結果・終局の結果の画面で「👁 卓を見る」を押すと結果が隠れて、最後の河を確認できます（ロンした牌には印がつきます）。「📋 結果を見る」で戻れます。
- **局の振り返り**：結果画面で、和了った役の説明（タップ）・符の内訳・この局のあなたの打牌評価をまとめて表示。
- **牌の名前はカタカナ**：牌の読み方（イーワン・リャンピン・サンソー…、字牌はトン・ナン・シャー・ペー・ハク・ハツ・チュン）を、手牌の下に2段で表示（設定でオン・オフ）。助言や解説の文章も「ウーピンを切る」のように、麻雀で使う呼び方で書いています。
- **麻雀用語の読み**：スジは「1-4-7（イースーチー）・2-5-8（リャンウーパー）・3-6-9（サンローキュー）」、順子は「123（イーリャンサン）」のように、解説に読みを添えています。解説の「牌の名前」タブに、全34牌の名前・数字の読み方・スジの言い方の一覧があります。
- **初心者向け**：牌の名前表示、役一覧・用語集・点数早見表つき。

### 🧠 定石クイズ100選（対戦とは別の機能）

タイトル画面の「🧠 定石クイズ100選」から、対戦とは別に、**型（パターン）で覚えて上達する**クイズに挑戦できます。

- **6分野・40の型・100問**：牌効率（何切る）／待ちの形／守り（放銃しない）／鳴きの判断／役と点数／局面の判断。各分野に「覚えるための型」（一言ルール＋くわしい説明＋図）があり、問題は必ずどれかの型に属します。
- **答えと数字は、エンジンが計算**：何切る（受け入れ枚数の比較）・待ち（残り枚数）・安全度（現物・スジ・カベ）・点数（翻・符・点数）・シャンテン数は、麻雀エンジンの計算結果と照らし合わせています（全問をテストで確認）。答えたあとの解説に、その計算結果の表が出ます。
- **いろいろな出題**：手牌から切る牌をタップ／待ちの牌を全部選ぶ／リーチを受けて安全な牌を選ぶ／鳴く・鳴かない／点数・符・翻を答える。
- **覚えたかどうかを記録**：同じ問題に2回続けて正解すると「覚えた」。分野ごとの進み具合、正解率、「苦手を復習」（間違えて、まだ覚えていない問題）、「ランダム10問」、「最初から順番に（続きから）」で繰り返し練習できます。進み具合はブラウザに保存されます。
- 答えたあとに「この型の解説を読む」で、その場で型の説明を開けます。「わからない」を押せば、答えを見て学べます。

### ⚙ カスタムできるルール

東風戦/半荘戦・持ち点/返し・ウマ/オカ・赤ドラ（0/3/4枚）・喰いタン・後付け・一発・裏ドラ・カンドラ・飛び・ダブロン/頭ハネ・途中流局（九種九牌/四風連打/四家立直/四槓散了/三家和）・流し満貫・西入・アガリやめ・連荘条件・数え役満・切り上げ満貫・ダブル役満。
プリセット（標準／はじめて向け／プロリーグ風／昔ながら）からも選べます。

CPU の強さ（よわい／ふつう／つよい）と進行速度も変更できます。

## 開発

```bash
npm install
npm run dev          # 開発サーバー（スマホからは同じ Wi-Fi で http://<PCのIP>:5173）
npm test             # 点数計算・シャンテン数・CPU 同士の対局シミュレーションのテスト
npm run build:single # 公開用（1つの index.html にまとめる）→ dist-single/
```

### 構成

```
src/engine/   ゲームのロジック（画面に依存しない）
  tiles.ts      牌の表現
  shanten.ts    シャンテン数・受け入れ
  yaku.ts       和了判定・役・符・点数
  game.ts       対局の進行（状態は JSON にできるプレーンなオブジェクト）
  safety.ts     危険度（現物・スジ・壁）
  analysis.ts   打牌の評価（CPU とヒントで共通）
  aim.ts        狙える役の一覧と、その役で和了できる見込み（%）
  ai.ts         CPU の思考
  advisor.ts    打ち筋サポートの解説文
src/screens/  タイトル・対局・設定・解説の画面
src/components/ 牌（SVG）・卓・結果画面
```

## 公開（GitHub Pages）

`main` に push すると `.github/workflows/deploy.yml` がテスト → ビルド → 公開します。
初回だけ、リポジトリの **Settings → Pages → Source** を **GitHub Actions** にしてください（自動で有効化されない場合）。
